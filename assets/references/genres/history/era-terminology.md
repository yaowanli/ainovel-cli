# 时代称谓对照表

本文件是**静态资料**，不经过模型生成，因此可直接作为机械检查的依据（经
`/rules era <朝代>` 载入为待裁决候选）。它与 `style-references.md` 的分工：
后者是软性写作提示，本表是「哪个词属于哪个朝代」的事实对照。

## 为什么是静态表而不是让模型生成

时代称谓是典型的「模型不可靠」任务：知识检索型、无推理深度、但错一条就会
被系统当作权威强制改写正文。实测让模型生成东汉称谓表：`reasoning_effort=medium`
下思考 5 分钟仍未产出，或思考烧完预算导致输出被截断。慢且不稳，不适合放进
创作主链路。

## 表格格式

每条：**禁用词 → 该时代写法**。`note` 说明依据年代，供人工复核。

### 称谓与敬语

- **相公** → 郎君 / 君 / 先生 | 唐指宰相（李相公），明清才通行为丈夫、士人的通用称呼。东汉绝无
- **大人** → 长者 / 丈人 / 翁 | 汉之「大人」指父母长辈或长者；明清才作对男性的敬称
- **娘子** → 妇人 / 夫人 | 唐宋已有「娘子」，但作为对女性配偶的通行称是明清以后
- **媳妇** → 妇 / 妇人 | 宋以后通行
- **大哥** → 长兄 / 丈人 | 宋代以后才作为口语称呼长者
- **老哥** → 兄 / 朋友 | 明清口语
- **掌柜** → 店主 / 掌事 | 明清市井通行
- **伙计** → 仆 / 僮 / 家人 | 明清商铺称谓
- **小姐** → 女 / 女子 | 明清以后
- **夫人** → 妇人 / 内子 | 「夫人」汉已有，但多指爵位封号；作对已婚女性的日常称呼是后世俗法
- **内人** → 内子 | 「内人」唐宋才见
- **拙荆** → 拙荆（可用）| 六朝已见，稳妥

### 官称与行政

- **知县** → 县令 | 明清户籍官名；汉置县令
- **知府** → 郡守 / 国相 | 明清官名
- **总督** → 刺史 / 太守 | 明清总督
- **总兵** → 将军 / 校尉 | 明清武职
- **内阁** → 尚书台 / 丞相府 | 明清中枢机构
- **六部** → 尚书台 | 吏户礼兵刑工六部为唐后所立，汉为尚书台
- **兵部** → 尚书台 / 兵曹 | 明清部名
- **衙门** → 官署 / 县寺 | 唐宋通行；汉称官署
- **锦衣卫** → 缇骑 / 刺史 | 明特务机构
- **东厂** → — | 明代机构，无对应
- **御史台** → 御史府 | 汉确有御史府，但明清御史台体制不同
- **尚书令** → 尚书令（慎用）| 汉尚书令为台主，权重远重于唐后同名官；东汉尚书台诸曹分曹治事
- **刺史** → 刺史（可用）| 汉武帝后置，六州部刺史
- **太守** → 太守（可用）| 汉郡长官
- **郡守** → 郡守（可用）| 汉
- **主簿** → 主簿（可用）| 汉
- **别驾** → 别驾（可用）| 汉州刺史属官

### 器物与生活

- **玻璃** → 琉璃 | 明清方见玻璃器；汉有琉璃但非日用玻璃
- **眼镜** → — | 明中期传入
- **火铳** → 弩 / 矢 | 明代才有火铳
- **棉花** → 麻 / 絁 | 棉花宋元方普及
- **茶馆** → 茶肆 | 「茶馆」明清通行
- **客栈** → 客舍 / 逆旅 | 「客栈」宋以后通行
- **银子（作货币量词）** → 钱 / 谷 | 以「两」计银为宋以后惯例
- **一贯** → — | 宋以后钱帛计量单位
- **铳** → 弩 | 明
- **自行车 / 火车** → — | 近世

### 制度与观念

- **科举** → 察举 / 孝廉 / 征辟 | 隋唐始行科举；汉以察举、征辟取士
- **进士** → 孝廉 / 茂才 | 唐以后指及第者
- **秀才** → 孝廉 / 茂才 / 游士 | 「秀才」在汉意为优异人才，不指生员
- **举人** → 被举者 | 宋以后指应举者；汉「举人」泛指被举荐入仕之人
- **解元 / 状元** → — | 宋元明清
- **朝廷** → 朝 / 朝廷（可用）| 汉已有「朝廷」一词，可放心使用
- **陛下** → 陛下（可用）| 汉已有
- **圣旨** → 诏书 / 制书 | 「圣旨」明清口语
- **旨意** → 制 / 诏 | 可用性存疑，慎用

### 神话与道教（汉代易混）

- **修炼** → 修身 / 导引 / 存神 | 道教内丹「修炼」为唐宋以后语汇
- **宗门** → 门生 / 师门 | 宗门为佛道后世俗法
- **秘境** → 洞天 / 福地 | 秘境为小说语汇
- **渡劫** → 天谴 / 雷劫 | 佛教东传后才有
- **灵石** → 玉 / 钱 | 灵石为修真小说语汇
- **筑基** → — | 内丹术语，唐宋以后
- **金丹** → 丹砂 / 黄金 | 汉「金丹」多指药物；后世专指道家内丹

## 边界与不确定项

拿不准的词宁可回避或改用泛称，不要硬套。本表带 ⚠ 的是历史上**跨时代有歧义**
的条目，采纳前请自行判断本书语境：

- ⚠ **大人**：汉亦可用于尊称官员（如「某大人」见于后世文献），但东汉口语中指
  父母长辈更常见。若书中用于尊称官员，可不禁。
- ⚠ **秀才**：汉代「秀才」是才能优异者，与明清生员含义完全不同。若主角是被
  举荐为孝廉者，可写作「孝廉」而非「秀才」。
- ⚠ **名堂**：明清指「名堂」门道，汉无此词，但「堂」本身汉有。

# 其他朝代补充条目

以下按朝代给出「该朝代不应出现」的词。`→` 后是该朝代可用写法。

## 三国两晋南北朝

- **陛下** → 可用（承汉制）
- **丞相** → 可用
- **都督** → 可用（魏晋都督州区）
- **州牧** → 可用
- **科举** → 察举 / 九品中正
- **进士** → 征辟
- **秀才** → 孝廉 / 茂才

## 隋唐

- **科举 / 进士 / 举人** → 可用（科举始于隋，成熟于唐）
- **状元** → 状头 / 进士科魁（唐无「状元」固定称呼）
- **尚书令** → 尚书令（唐为虚衔，非实权）
- **相公** → 相公（唐指宰相，可用，但非丈夫义）
- **内阁 / 六部** → 六部可用（三省六部制），内阁不可
- **知县 / 县令** → 县令

## 宋

- **状元** → 可用
- **知县 / 知府** → 县令 / 郡守
- **包公 / 铡** → 避讳争议大，慎用
- **内卷 / 躺平** → —

## 元

- **知县** → 可用（元沿用）
- **状元** → 可用
- 蒙古语借词大量进入汉语，另有独特称谓体系

## 明

- **状元** → 可用
- **内阁 / 首辅 / 东厂 / 锦衣卫 / 知县 / 总督 / 玻璃 / 眼镜 / 火铳** → 可用
- **相公** → 可用（明清通行）
- **娘子 / 媳妇 / 掌柜 / 伙计 / 老爷** → 可用

## 清

- **状元** → 可用
- **内阁 / 军机处** → 军机处不可（清中枢）
- **老爷** → 可用（清代极通行）
- **大人** → 可用（清代敬称）
